# 짝꿍 만나러 가요! 주사위

유아용 4인 말판 게임 《짝꿍 만나러 가요!》에서 쓰는 폰 주사위예요. 말판은 탁자 위에 두고, 주사위만 폰으로 던져요.

- 정팔면체 주사위: 1(2면) · 2(3면) · 3(2면) · 펑(1면, 쉬어 가요)
- 같은 테이블 번호로 연 폰끼리(몇 대든) 던진 결과가 실시간으로 함께 보여요
- 페스타 테이블 주소: `?t=1`, `?t=2`, `?t=3` (같은 번호끼리 함께 봐요. 페스타 마지막 날 2026-11-28이 지나면 자동으로 언제든 놀이로 열려요)
- 온라인 놀이: `board.html` — 폰·태블릿 하나를 돌려 가며 2~4명이 두더지 말을 움직여요. 그림 칸에 서면 질문 카드가 저절로 뜨고, 친구네 집에 들어가면 성공
- 언제든 놀이: 번호 없는 주소로 열면 그 폰만의 방이 새로 생겨요. 같이 놀 폰은 화면의 '함께할 폰 연결하기' QR로만 들어와요
- 실시간 연결: 가입이 필요 없는 공개 MQTT 중계(EMQX, HiveMQ)
- 그림 칸 질문: 생각해요·확인해요·골라요·지켜요·하이파이브 버튼을 누르면 질문 카드가 뜨고 음성(`audio/`)이 나와요. 같은 테이블의 다른 폰에도 같은 카드가 보여요
- `jjakkung-qr.pdf`: 테이블 1~3번 QR 인쇄용
